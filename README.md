# Pakka

**Check before you pay.**

Paste a message — a PG listing, an internship offer, a "your KYC has expired"
SMS — and Pakka tells you whether it looks like a scam, which specific parts
gave it away, and why. You get a link you can forward back to whoever sent it.

Built for First Commit (AWS × WeMakeDevs), 17–20 September 2026.
