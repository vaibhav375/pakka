    How it decides

    A model never
    gets the last word.

    A scam verdict has to be the same every time and has to survive being explained to the person who nearly paid. So rules decide, and everything else is evidence shown beside them.

    01

    Rules decide

    Forty-seven checks, each able to point at the exact words that set it off. Same message, same answer, every time. Nothing overrules them.

    02

    A model widens the net

    Rules are blind to phrasings nobody wrote down. A linear model trained on 5,700 labelled messages catches those, and because it is linear it can show which characters it reacted to. It can raise a warning. It cannot clear a message the rules flagged.

    03

    It stays with you

    Rules and model are both 11 KB of arithmetic running in the browser, so nothing is sent anywhere until you choose to share. Shared scans carry a 30-day TTL and delete themselves.
