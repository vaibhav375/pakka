    How it decides

    A model never
    gets the last word.

    A scam verdict has to be the same every time and has to survive being explained to the person who nearly paid. So the decision is made by rules you can read.

    01

    Rules decide

    Thirty-four checks, each one able to point at the exact words that set it off. Same message, same answer, every time.

    02

    The model only phrases it

    Language models are good at wording and bad at being certain. It writes the summary sentence. It cannot change the verdict.

    03

    It stays with you

    The rules run in the browser, so nothing is sent anywhere until you choose to share. Shared scans carry a 30-day TTL and delete themselves.
